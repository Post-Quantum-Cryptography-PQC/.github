# Post Quantum Cryptography (PQC)

Open **learning materials** and a **curated map of PQC research papers** — so more people can enter the field and find the right literature.

## Start here

- **[PQC Learn](https://post-quantum-cryptography-pqc.github.io/learning/)** — fundamentals → bridge → concepts → research tracks
- **[Paper map](https://post-quantum-cryptography-pqc.github.io/learning/papers/)** — search / filter / sort; **click a title** for the publisher DOI or ePrint URL (download PDFs yourself — we do not host them)
