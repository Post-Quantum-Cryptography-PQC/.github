# Post Quantum Cryptography (PQC)

Open **learning materials** and a **curated map of PQC research papers** — so more people can enter the field and find the right literature.

## Start here

**[PQC Learn](https://post-quantum-cryptography-pqc.github.io/learning/)** — fundamentals → bridge → concepts → research tracks.

Written for motivated newcomers. No course prerequisite assumed.

## Research paper map

We index papers we study (theory, hardware, implementation, side-channel, and related venues) by **title, venue, category, and publisher / ePrint URL**.

You download papers from the official source (IEEE Xplore, IACR ePrint, DOI, …). We do **not** redistribute PDFs.

A public catalog export is planned next on the learning site; the live curriculum already reflects the topics we teach from that map.
